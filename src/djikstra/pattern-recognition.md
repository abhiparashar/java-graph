## 📋 **Quick Reference - Pattern Identification**

### **⚡ INSTANT TRIGGERS:**
- **"Shortest/Minimum/Cheapest" + "Weighted Graph" = Dijkstra**

### **4 CORE PATTERNS:**
1. **BASIC DIJKSTRA:** Single source, positive weights, find shortest distances
2. **MODIFIED DIJKSTRA:** Additional constraints (stops, moves, conditions)
3. **DIJKSTRA VARIANTS:** Different objectives (maximize, minimize-the-maximum)
4. **MULTI-SOURCE DIJKSTRA:** Multiple starting points, find nearest

## 🚨 **RED FLAGS - NOT DIJKSTRA:**

❌ **"Negative edge weights"** → Bellman Ford  
❌ **"All pairs shortest path"** → Floyd Warshall  
❌ **"Unweighted graph shortest path"** → BFS  
❌ **"Topological ordering"** → DFS/Kahn's Algorithm  
❌ **"Detect cycle"** → DFS/Union Find  
❌ **"Minimum spanning tree"** → Kruskal/Prim
