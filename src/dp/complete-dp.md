## 📚 TOPIC-WISE BREAKDOWN

### 🔢 Linear DP (1D) - 25 problems
**Easy**: 8 problems | **Medium**: 15 problems | **Hard**: 2 problems

**Key Patterns:**
- Fibonacci-like recurrence: `dp[i] = dp[i-1] + dp[i-2]`
- Decision making: `dp[i] = max/min(take, skip)`
- State transitions with constraints

**Essential Problems:** 70, 198, 322, 300

### 🏠 Grid DP (2D Paths) - 18 problems
**Easy**: 3 problems | **Medium**: 12 problems | **Hard**: 3 problems

**Key Patterns:**
- Path counting: `dp[i][j] = dp[i-1][j] + dp[i][j-1]`
- Min/max path sum: `dp[i][j] = grid[i][j] + min/max(...)`
- Obstacle handling and boundary conditions

**Essential Problems:** 62, 64, 174, 741

### 📝 String DP - 22 problems
**Easy**: 1 problem | **Medium**: 8 problems | **Hard**: 13 problems

**Key Patterns:**
- Substring problems: `dp[i][j]` represents substring from i to j
- Subsequence matching: LCS, edit distance
- Pattern matching: regex, wildcard

**Essential Problems:** 5, 72, 1143, 139

### 🎒 Knapsack Variants - 8 problems
**Easy**: 0 problems | **Medium**: 6 problems | **Hard**: 2 problems

**Key Patterns:**
- 0/1 Knapsack: `dp[i][w] = max(dp[i-1][w], dp[i-1][w-weight] + value)`
- Unbounded Knapsack: can use items multiple times
- Multi-dimensional constraints

**Essential Problems:** 416, 322, 474

### 📈 Subsequence DP - 12 problems
**Easy**: 1 problem | **Medium**: 8 problems | **Hard**: 3 problems

**Key Patterns:**
- LIS template: `dp[i] = max(dp[j] + 1)` for all j < i where nums[j] < nums[i]
- Counting subsequences
- Multi-dimensional LIS

**Essential Problems:** 300, 673, 354

### 🎮 Game Theory DP - 8 problems
**Easy**: 1 problem | **Medium**: 4 problems | **Hard**: 3 problems

**Key Patterns:**
- Minimax: `dp[i][j] = max(score[i] - dp[i+1][j], score[j] - dp[i][j-1])`
- First player advantage calculation
- Optimal strategy for both players

**Essential Problems:** 877, 486, 1510

## 💡 KEY INSIGHTS

### DP Problem Recognition:
1. **Optimal substructure**: Solution can be built from optimal solutions to subproblems
2. **Overlapping subproblems**: Same subproblems are solved multiple times
3. **Keywords**: "maximum/minimum", "count ways", "is it possible", "optimal"

### Common Mistakes:
1. **Wrong state definition**: Always define what dp[i] represents clearly
2. **Base case errors**: Handle edge cases and initial states properly
3. **Space optimization premature**: Get correct solution first, then optimize space

### Optimization Tips:
1. **Space optimization**: Often 2D DP can be reduced to 1D
2. **Binary search + DP**: For problems like LIS
3. **Monotonic queue/stack**: For sliding window maximum problems
