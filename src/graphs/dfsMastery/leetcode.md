## 💡 **Pro Tips for LeetCode Practice**

### **Approach Strategy:**
1. **Read problem** → identify pattern using cheat sheet
2. **Plan solution** → which BFS/DFS pattern?
3. **Code** → implement the pattern
4. **Test** → verify with examples
5. **Optimize** → check time/space complexity

### **Time Management:**
- **Easy problems:** 15-20 minutes
- **Medium problems:** 30-45 minutes
- **Hard problems:** 60+ minutes (don't spend more than 90 mins)

### **When Stuck:**
1. Re-read problem for BFS/DFS trigger words
2. Check if similar to our 9 patterns
3. Look at constraints (small n = DFS ok, large n = BFS better)
4. Draw the problem on paper

**Start with starred (⭐) problems - ye interview mein definitely aate hain!** 🚀
