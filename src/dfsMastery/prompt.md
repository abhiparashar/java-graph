  **Use DFS when:**
* Need to explore ALL paths/solutions
* Backtracking required
* Path tracking needed
* Memory efficient for deep searches
  **Use BFS when:**
* Shortest path needed
* Level-by-level processing
* Multi-source scenarios
* Guaranteed to find closest solution
